# Каталог DOI · ЛР2

Flutter-каталог датасетов, статей и других научных записей в формате DataCite. В каталоге 20 локальных записей.

## Запуск

```sh
flutter pub get
flutter gen-l10n
flutter run -d chrome --no-web-resources-cdn
flutter run -d windows
```

Для Windows нужна Visual Studio 2022 с компонентом **Desktop development with C++**. Вместо Chrome можно указать `-d edge`.

В шапке можно переключить светлую и тёмную тему и выбрать русский или английский интерфейс. Настройки действуют до перезапуска. Поиск работает по заголовку и DOI. После возврата из деталей сохраняются запрос, результаты и позиция списка.

Для проверки связей откройте **Global Sea Surface Temperature** и выберите DOI `10.1234/ncomms.2024.1987` в секции связанных записей. Первый возврат ведёт к исходной записи, второй — к списку. Связь с отсутствующим DOI открывает экран «Записи нет в каталоге».

## Код

- `lib/l10n` содержит две ARB. Flutter генерирует из них `AppLocalizations`.
- `lib/features/doi/domain` содержит модель и контракт `IDoiRepository`.
- `lib/features/doi/data` содержит моки, маппер JSON:API и реализацию репозитория. Источник данных подключается через этот репозиторий.
- `lib/features/doi/presentation` содержит Cubit, sealed-состояния, экраны и форматирование полей.
- `lib/common/navigation` задаёт маршруты `/` и `/doi/:id`. Маршрут принимает DOI и с обычным слешем, и с `%2F`.
